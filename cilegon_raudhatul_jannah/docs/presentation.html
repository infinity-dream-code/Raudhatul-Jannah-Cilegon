Ikhtisar Produk
3 Pilar Utama Layanan Facepay Alizzah

🛒 FacePay Kantin

Transaksi cashless berbasis pemindaian wajah real-time. Kasir memindai wajah siswa, verifikasi nama, inquiry saldo, dan eksekusi pembayaran belanja.

📋 Panel Admin

Pusat kontrol absensi presensi wajah harian, pengelolaan data siswa, perekaman sampel foto referensi, serta pemantauan saldo.

👨‍👩‍👧 Portal Ortu Mandiri

Antarmuka mobile-first bagi orang tua untuk memperbarui foto wajah anak secara mandiri dilengkapi Oval Face Guide & upload dari galeri.

Arsitektur Informasi
4 Modul Navigasi & Jalur Akses Sistem

Portal Utama ( / )

Pintu gerbang utama untuk memisahkan jalur bagi Petugas Kantin, Administrator, dan Orang Tua Siswa.

Modul Kantin ( /kantin/ )

Terminal kasir kantin untuk identifikasi wajah, Inquiry Saldo, dan Payment Belanja (Auth Merchant JWT).

Modul Admin ( /admin/ )

Panel manajemen sekolah untuk absensi harian, pendaftaran siswa, rekam referensi, dan konfigurasi.

Portal Ortu ( /ortu/ )

Portal mandiri orang tua untuk pendaftaran foto wajah siswa dengan Oval Guide & unggah galeri.
